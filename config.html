Configuración del motor y las alertas

Los cambios se guardan como un commit en engine/config.json y alerts/telegram.json. La próxima corrida del motor de señales ya usa los valores nuevos.

Entrar con tu cuenta de GitHub

Solo quien tiene permiso de escritura en el repositorio puede guardar cambios. Para entrar usás un token de acceso de GitHub limitado a este repo. El token queda únicamente en este navegador y viaja solo a api.github.com.

  1. Abrí crear token en GitHub (tipo Fine-grained).
  2. En Repository access elegí Only select repositories y marcá TraderPanel.
  3. En Permissions → Repository: Contents: Read and write. Opcional: Actions: Read and write para poder correr el motor apenas guardás.
  4. Ponele vencimiento (90 días está bien), generalo y pegalo acá.
