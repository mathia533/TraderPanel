Entrar a la configuración

Usás un token de GitHub. Queda solo en este navegador y viaja solo a api.github.com. Tu perfil se identifica con tu usuario de GitHub; solo quien tiene permiso de escritura en el repo puede guardar.

  1. 1
    Abrí crear el token en GitHub: el link ya trae marcados el repo TraderPanel y los permisos (tipo Fine-grained).
  2. 2
    Revisá que diga Contents: Read and write. Opcional: Actions: Read and write para correr el motor apenas guardás.
  3. 3
    Ponele vencimiento (90 días está bien), generalo y pegalo abajo.

  2. 2

  3. 3
    Ponele vencimiento, generalo y pegalo abajo.
