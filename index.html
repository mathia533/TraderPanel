Cómo conectar el canal
  1. En Telegram, hablale a @BotFather, mandá /newbot y guardá el token que te da.
  2. Creá un canal y agregá al bot como administrador con permiso para publicar.
  3. En GitHub: Settings → Secrets and variables → Actions, cargá TELEGRAM_BOT_TOKEN (el token) y TELEGRAM_CHAT_ID (el @ del canal, o su id -100… si es privado).
  4. Tocá Mandar mensaje de prueba y después Run workflow con la casilla de prueba marcada.

El token queda solo en GitHub; este panel nunca lo ve.
